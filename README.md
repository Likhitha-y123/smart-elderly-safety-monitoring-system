# Smart Elderly Safety Monitoring System

## Project Overview
The Smart Elderly Safety Monitoring System is designed to improve the safety and well-being of elderly people by providing medicine reminders and alerts for potential emergency situations. The system integrates sensors and alert mechanisms to monitor selected safety conditions and help caregivers respond when assistance may be required.

Our team secured **2nd place in the Innovate-X Ideathon under the Hardware Track**.

## Objectives
- Improve elderly safety through sensor-based monitoring.
- Provide reminders for scheduled medication.
- Enable emergency alerts through a push button.
- Detect potential falls and monitor movement.
- Identify gas leakage and provide an alert.

## Key Features
- Medicine reminders
- Emergency alert using a push button
- Fall detection using a tilt sensor
- Motion detection using a PIR sensor
- Gas leakage detection
- Visual and audible alerts using an LCD, buzzer, and LED

## Components Used
- Arduino Uno
- PIR motion sensor
- Gas sensor
- Tilt sensor
- Push button
- 16×2 LCD display
- Buzzer
- LED

## Tools and Technologies
- Tinkercad Circuits
- Arduino IDE
- Embedded Systems
- Sensor Interfacing
- Circuit Design

## Working Principle
The system uses sensors and a push button to monitor selected safety conditions. The controller processes the input signals according to the programmed logic and activates suitable visual or audible alerts when specified conditions are detected. The medicine reminder function is intended to notify the user at scheduled times.
