# Smart Elderly Safety Monitoring System

## Project Overview

The Smart Elderly Safety Monitoring System is an electronics-based project designed to demonstrate safety monitoring and emergency alert features for elderly people. The system integrates sensors, a display, and alert components to support monitoring of movement and environmental conditions.

The circuit is designed and simulated using Tinkercad Circuits. It demonstrates how electronic components can work together to provide visual and audio alerts when specific conditions are detected.

## Objectives

- Design an electronic circuit for elderly safety monitoring.
- Integrate sensors and output devices with a controller.
- Provide visual and audio alerts for specified conditions.
- Demonstrate motion monitoring and emergency assistance functions.
- Explore the use of embedded electronics in healthcare and safety applications.

## Hardware Components

The circuit includes the following components:

- Arduino Uno controller
- PIR motion sensor for detecting movement
- Gas sensor for monitoring gas-related conditions
- 16×2 LCD display for displaying system messages
- Buzzer for audio alerts
- LED for visual indication
- Push button for manual input or emergency activation
- Resistor and connecting wires

## Working Principle

The system uses a controller to receive inputs from the connected sensors and push button. Based on the programmed conditions, it can process the inputs and activate the display or alert components.

1. **Motion Detection:** The PIR sensor detects movement within its sensing range.
2. **Gas Monitoring:** The gas sensor provides an input related to the presence of certain gases.
3. **Display Output:** The LCD displays system status or messages according to the program.
4. **Audio Alert:** The buzzer can provide an audible warning when a programmed alert condition is met.
5. **Visual Alert:** The LED indicates a system status or alert condition.
6. **Manual Input:** The push button provides a manual input for a programmed function.

The exact response of each component depends on the uploaded program and the conditions defined in the code.
